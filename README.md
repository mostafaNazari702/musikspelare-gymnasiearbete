# Musikspelare Gymnasiearbete

## About
This project was created as part of my studies and school work (Gymnasiearbete).  
The purpose of this repository is educational and experimental.

## Features
- Music player functionality using Lavaplayer
- Audio playback controls ( limited to only pause/resume )
- User interface for managing music ( a very simply one )
- Educational programming project

## Installation
Clone the repository:

```bash
git clone https://github.com/mostafaNazari702/musikspelare-gymnasiearbete.git
```

Go into the project folder:

```bash
cd musikspelare-gymnasiearbete
```

Run the project according to your development environment.
